# Vastralaxmi Fashion — Setup Outline

Full step-by-step guide will be completed in `SETUP.md` after the theme and plugin are built.

## One-by-one order

1. Start the Local site (localhost router mode / `http://localhost:PORT`)
2. Activate plugin `VL Core`
3. Activate theme `Dynamic Fashion Theme`
4. Set Permalinks to **Post name** and save
5. Run seed (Tools → VL Seed Content) or create categories manually
6. Add products from Products → Add New
7. Create advertisements for each slot
8. Assign Primary and Footer menus
9. Set a static front page if needed (theme uses `front-page.php`)
10. Test Home, category archives, product/article singles, and mobile layout
